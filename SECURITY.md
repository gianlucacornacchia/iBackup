# Security Policy

iPhone Archive handles personal photos and talks to a paired iPhone, so
security and data-loss bugs are taken seriously.

## Supported versions

The project is pre-release. Only the latest commit on `main` is supported.

## Reporting a vulnerability

Do not report security issues or data-loss bugs in a public issue. Use
GitHub's [private vulnerability reporting](https://github.com/gianlucacornacchia/iBackup/security/advisories/new)
instead.

Please include:

- what an attacker or a failure could do (for example, read or alter archive
  files, delete media, or bypass a deletion confirmation)
- the steps to reproduce it, using a disposable archive
- the affected commit or version

You can expect an acknowledgement within a week.
